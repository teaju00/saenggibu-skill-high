# 내 교과 정보 (교사가 채움)

이 파일은 교사가 학기 초에 한 번 채워 두는 칸이다. AI는 세부능력 및 특기사항을 쓸 때 이 파일의 성취기준을 기준으로 삼는다.

- 성취기준은 **교육과정 원문 그대로** 붙여 넣는다. 국가교육과정정보센터나 학교 교육과정 문서에서 복사한다.
- AI에게 성취기준을 만들어 달라고 하지 않는다. 칸이 비어 있으면 AI는 쓰기 전에 성취기준을 요청한다.
- 과목이 둘 이상이면 이 파일을 과목마다 하나씩 만든다. 파일 이름에 과목명을 붙인다. 예: `0. 내 교과 정보 (물리학 2학년).md`
- 학생 개인정보는 이 파일에 적지 않는다. 학교명, 학교 고유 행사·프로그램 이름도 적지 않는다(고교 블라인드).

## 1. 기본 정보

```
과목:
학년:                      (1·2학년 = 2022 개정 / 3학년 = 2015 개정)
학기:                      (1학기 / 2학기 / 두 학기 모두)
학점(단위):
과목 유형:                  (공통 / 일반 선택 / 진로 선택 / 융합 선택 / 체육·예술 / 교양(P) / 전문교과 / 학교 밖 교육 / 공동교육과정 · 온라인학교)
소논문 작성 가능 과목 여부:   (수학과제 탐구, 사회문제 탐구, 융합과학 탐구, 과학과제 연구, 사회과제 연구, 윤리문제 탐구(1·2학년) 중 하나인지)
세특 기본 분량(Byte):       (비우면 1,500Byte. 1·2학년 공통과목은 1·2 합산 1,500Byte)
학기별 입력 여부:           (학기마다 따로 입력 / 학년 말 한 번)
```

고등학교 세특은 모든 학생에게 쓰는 것이 원칙이다. 관찰이 거의 없는 학생을 '특이사항 없음.'으로 둘지는 학업성적관리위원회가 정한다.

## 6. 교과협의회·학교 결정 사항 (선택)

학교마다 정한 표기 관례가 있으면 적는다. AI는 이 결정을 기재요령 범위 안에서 따른다.

```
예: 학기 구분 없이 학년 말에 한 번 입력함
예: 모든 학생 세특은 1,200Byte 안팎으로 맞춤
예: 수업에서 쓴 도구 이름은 '텍스트 기반 프로그래밍 환경'처럼 일반 명칭으로 통일
```
