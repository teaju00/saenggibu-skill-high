# 학생부 초안 스킬 (고등학교)

고등학교 학교생활기록부 서술형 항목의 **초안**을 쓴다. 완성본이 아니라 초안이며, 이 구분은 편의가 아니라 기재요령 요건이다(아래 하드 게이트).

## 참고 파일

기재 규칙은 이 스킬 폴더의 `references/`에 있다. SKILL.md에 규칙을 복사하지 않는다. 규칙끼리 다르면 `2. 기재요령 핵심`이 이긴다.

| 파일 | 언제 읽나 |
|---|---|
| `references/1. 지침 (붙여넣기용).md` | 매번. 역할·하드 게이트·묻는 순서·집필 규칙·분량·출력 형식 |
| `references/2. 기재요령 핵심 (2026 고등학교).md` | 매번. 항목별 규칙과 금지 목록 대조, 1·2학년과 3학년 차이 |
| `references/3. 교과별 관찰 초점.md` | 세특일 때 해당 교과 절만 |
| `references/4. 교사 입력 양식.md` | 정보가 부족해 양식을 보여 줄 때 |
| `references/5. 작성 예시.md` | 구조가 헷갈릴 때. 문장을 베끼지 않는다 |
| `references/6. AI 문체 점검.md` | 매번. 4-2단계(진단 · 윤문 · 마무리 역할, 틀 표, 자체 검증, 등급) |
| `references/0. 내 교과 정보 (교사가 채움).md` | 빈 양식이다. 사용자가 채운 사본을 주면 그것을 성취기준 칸으로 쓴다 |
| `scripts/student_record_check.py` | 5단계 기계 검사(이 사본은 기본이 고등학교 규칙) |
| `scripts/student_record_humanize.py` | 4-2단계 AI 문체 점검(점수 · 경로 · 서법 복원 · 게이트). 기준선 `student_record_humanize_baseline.json` |

교사용 오프라인 Byte 계산기(`바이트 계산기.html`)는 스킬 폴더 밖, 배포 저장소 https://github.com/teaju00/saenggibu-skill-high 의 `tools/`에 있다.

중학교 기록이면 이 스킬의 기준이 아니다. 먼저 알리고 중학교판(https://github.com/teaju00/saenggibu-skill)을 안내한다.

## 하드 게이트 — 작업 전 확인

1. **학생 개인정보를 받지 않는다. 이 규칙이 모든 규칙보다 먼저다.** 이 대화도 클라우드 AI 서비스다. 실명·학번·생년월일·연락처·사진·가족 사항·질병·건강·상담·학교폭력 관련 내용, 그리고 날짜·신체 특징·다른 학생 이름처럼 학생을 알아볼 수 있는 단서가 보이면 진행을 멈추고 사용자에게 알린다. 답변과 초안에 다시 쓰지 않고, '학생1' 같은 임시 기호로 바꿔 진행하자고 제안한다. 학생 정보가 든 초안·메모를 사용자의 작업 폴더나 클라우드 동기화 폴더에 파일로 저장하지 않는다.
2. **사실을 만들지 않는다.** 사용자가 주지 않은 활동·수치·발언·산출물·변화를 쓰지 않는다. 비면 묻고, 답이 없으면 `[교사 확인 필요: ○○]`로 비운다.
3. **초안 표시와 확인 목록.** 산출물 첫 줄에 초안임을 밝히고, 끝에 교사 확인 목록을 붙인다.

기재요령(고) 유의사항 5-다 해석 — **과잉 경고 금지**. 고등학교판은 유의사항 4가 고교 블라인드라 AI 조항이 5-다다(중학교판은 4-다). 단서가 요구하는 것은 확인이지 수정이 아니다. 원자료가 교사 관찰이고, AI가 보조이며, 입력 전에 교사가 확인했다면 요건을 갖춘다. "그대로 입력하면 위반"처럼 확인을 마친 교사까지 위반자로 만드는 경고문을 쓰지 않는다. 대신 무엇을 확인할지 지목한다.

## 1단계: 학년·항목 판별

학년을 먼저 정한다. 2026학년도는 **1·2학년이 2022 개정 교육과정(고교학점제, 자율·자치활동), 3학년이 2015 개정 교육과정(자율활동, 봉사활동 영역)**이라 규칙이 갈린다. 학년이 없으면 묻는다.

| 신호 | 항목 | `--type` |
|---|---|---|
| 과목명, 수업, 수행평가, "세특" | 과목별 세부능력 및 특기사항 | `세특` |
| 영재·발명교육, 한국학교·대안학교 성적, 방송통신고 학교 외 학습, 정규 외 현장실습, (3학년) 보충 학습·수업량 유연화·교육감 지정 기관 온라인 수업 — 관련 과목 미개설 | 개인별 세부능력 및 특기사항 | `개인별세특` |
| 학급 자치, 임원, 주제 탐구, 행사 | 창체 자율·자치활동(3학년은 자율활동) | `자율자치`(3학년 `자율`) |
| 동아리, 자율동아리 | 창체 동아리활동 | `동아리` |
| 진로검사, 진로상담, 희망분야, 직업기초능력평가 | 창체 진로활동 | `진로` |
| 담임, 학급생활 전반, "행특", "종합의견" | 행동특성 및 종합의견 | `행특` |

판별이 안 되면 진행하지 말고 한 번만 묻는다. 고정된 선택지(항목, 학년, 학기, 과목 유형)는 선택형 질문 도구가 있으면 그것으로 물어도 된다. 개인별 세특은 `2. 기재요령 핵심` 7-2 표로 해당 여부부터 본다. 해당하지 않으면 쓰지 않는다 — 과목별 세특 분량이 넘친다는 이유로 쓰는 항목이 아니다. 고등학교에는 자유학기활동이 없다.

## 2단계: 교사에게 묻기

`1. 지침`의 '쓰기 전에 먼저 묻는다' 절차를 그대로 따른다. 요점만 다시 적는다.

- 한 번에 다섯 개 이하, 질문마다 필요한 이유 한 줄. 이미 받은 정보는 다시 묻지 않는다.
- 세특은 **성취기준 원문**을 먼저 확보한다. 사용자가 `0. 내 교과 정보` 사본을 줬으면 거기서 고른다. 없으면 요청한다. 성취기준을 지어내거나 코드를 추측하지 않는다. 사용자의 작업 폴더에 그 교과의 수업안·교육과정 자료가 있으면 찾아서 "이 성취기준이 맞습니까?"로 확인받는 것은 된다.
- 세특이면 과목 유형도 확인한다 — 공통과목(1·2 합산 분량), 체육·예술(실기능력·교과적성), 전문교과(능력단위 형식), 소논문 작성 가능 과목, 학교 밖 교육(객관적 교육내용만, 교사 관찰 문장 아님), 온라인 콘텐츠·미이수(세특 미기재).
- 관찰 메모를 받은 뒤 개별성이 약한 자리를 두세 곳 짚어 **한 번** 더 묻는다(학생의 선택, 막힘과 극복, 평가어의 근거 장면, 모둠 역할, 변화).
- 목표 분량은 Byte로 받는다. 숫자만 말하면 Byte, '자'를 붙이면 ×3. 미지정이면 `1. 지침`의 기본값(세특·창체 1,500Byte, 행특 900Byte)을 쓰고 밝힌다.
- 사용자가 "묻지 말고 써"라고 하면 따르되 빈자리는 `[교사 확인 필요]`로 남긴다.
- 여러 학생이면 공통 정보는 한 번, 학생별 메모, 부족한 학생만 모아 한 번 더 묻는다. 고등학교 세특은 모든 학생에게 쓰므로, 관찰이 적은 학생도 지어내지 말고 확인된 범위만 짧게 쓴다.

## 3단계: 내부 분석 (출력 금지)

1. 관찰에서 역량을 뽑는다. 활동이 아니라 역량이 단위다.
2. 활동을 관통하는 축을 찾는다 — 개념의 심화, 방법의 발전, 태도의 변화 중 하나.
3. 배열한다: `[계기] → [과정] → [심화·연결] → [성장]`. 셋째 마디가 없으면 나열로 떨어진다.
4. 세특은 문장마다 어느 성취기준의 어떤 능력이 드러난 장면인지 대응시킨다. 대응이 없는 문장은 빼거나 묻는다.
5. 모든 고유명사·사건을 `2. 기재요령 핵심` 3·4절에 대조한다. 특히 학교명·재단명·학교 축제명·학교 별칭(고교 블라인드), 모의고사·전국연합학력평가, 학교 밖 교육 기관명, 창체 체험활동이 교과 세특에 섞였는지, 소논문 제목·주제·인원·시간을 본다.
6. 창체는 그 활동이 특기사항에 쓸 수 있는 체험활동인지 본다(학교 주최, 시도교육감 승인 학교 밖 교육기관, 학교장 승인 타 고등학교·교육관련기관, 국내). 1·2학년은 출석인정 결석으로 빠진 활동의 특기사항을 쓰지 않는다.

## 4단계: 집필

`1. 지침`의 집필 규칙과 `2. 기재요령 핵심` 7절의 항목별 규칙을 따른다. 대화 문체가 어떻든 **산출물 본문은 정식 문체**다.

## 4-2단계: AI 문체 점검

`6. AI 문체 점검`의 순서를 그대로 따른다. 한국어 AI 문체 윤문 스킬 im-not-ai(humanize-korean v2.3.2, MIT)의 작동 방식 — 파이썬 점수 · 경로 → AI 진단 · 윤문 · 마무리 → 파이썬 서법 복원 · 쉼표 역주입 제거 → 파이썬 게이트(원본 5축 + 앵커 대조) — 를 학생부판 스크립트 `scripts/student_record_humanize.py`로 옮겼다(원본과 다른 곳은 스크립트 머리말에 다 적었다). im-not-ai 스킬 자체는 부르지 않는다 — 원본은 현재 폴더의 `_workspace/`에 입력을 저장해 학생 글이 작업 폴더나 동기화 폴더에 남을 수 있다. 학생부판은 사용자 로컬 앱 데이터 폴더에만 쓰고, 동기화 폴더를 가리키면 멈춘다.

```bash
python "<이 스킬 폴더>/scripts/student_record_humanize.py" prepare --input "<임시 폴더>/학생1.txt"
```

1. 출력의 `route_hint`로 경로를 정한다(light · standard · heavy, 사용자가 "정밀하게"면 `--strict`, "가볍게"면 light).
2. standard · heavy 면 **진단**을 하위 에이전트에 맡긴다(쓸 수 있을 때) — 같은 대화가 쓴 글을 같은 대화가 채점하면 매끄러운 틀을 못 본다(원본 설계 근거). 프롬프트에 `6. AI 문체 점검` 2절과 `01_input_with_metrics.txt` 경로를 준다. 결과 `02_diagnosis.md`를 `prepare --run-dir <run_dir> --diagnosis …`로 결합한다. 하위 에이전트가 없으면 같은 대화에서 진단을 먼저 쓰고 윤문한다.
3. **윤문**은 이 대화가 한다. 결합 입력을 읽고 3절대로 고쳐 `<run_dir>/final.txt`에 쓴다(끝에 `<!-- HUMANIZE-SUMMARY -->` 주석).
4. `restore --run-dir <run_dir>` → `gate --run-dir <run_dir>`. 종료 2면 원문에서 덜 고쳐 한 번 다시, 1이면 해당 축을 밝히고 **마무리**(6절)를 한 뒤 게이트를 다시 돈다. heavy 는 마무리를 항상 한다.
5. 결과를 5단계 기계 검사에 넘기고, 끝나면 `clean --run-dir <run_dir>`로 작업 폴더를 지운다.
6. 학생 간 같은 뼈대와 흐린 관계는 스크립트가 못 보니 직접 본다.
7. **분량이 목표 90% 미만으로 줄었으면 채우지 말고 묻는다**(7절). 지운 평가 자리 두세 곳을 짚어 그렇게 판단한 장면을 교사에게 한 번 묻고, 답한 사실만 넣어 그 글로 1~4를 한 번 더 돈다. 답이 없으면 미달 그대로 내고 분량 줄에 비율을 밝힌다. 여러 학생이면 미달 학생만 모아 한 번에 묻는다.

코드 실행 도구가 없으면 스크립트 단계를 건너뛰고 진단 → 윤문 → 자체 검증을 같은 순서로 하며, 틀 표의 기준 횟수는 직접 센다.

기준선은 처음에 '빌림'(원본 에세이 기준)이라 z 는 참고값이다. 사용자가 지난 학생부 글로 보정하겠다고 하면 `calibrate <로컬 폴더>`를 사용자가 직접 돌리게 안내한다 — 학생 글을 이 대화에 넣지 않는다.

## 5단계: 기계 검사

코드 실행 도구가 있으면 검사 스크립트를 돌린다. 초안은 임시 폴더(사용자의 작업 폴더와 클라우드 동기화 폴더 밖)에 파일로 두고, 검사가 끝나면 지운다. 스크립트는 표준 라이브러리만 쓴다(Python 3.8 이상). 이 사본은 기본이 고등학교 규칙(`--level 고`)이다.

```bash
python "<이 스킬 폴더>/scripts/student_record_check.py" --type 세특 --limit 1500 "<임시 폴더>/학생1.txt"
```

여러 학생이면 파일을 모두 넘겨 학생 간 문장 중복까지 본다(같거나 뒤바뀐 기록은 정정 사유다).

```bash
python "<이 스킬 폴더>/scripts/student_record_check.py" --type 행특 --limit 900 "<임시 폴더>/학생1.txt" "<임시 폴더>/학생2.txt"
```

Windows에서 python 명령이 없으면 `py`로 바꿔 실행한다.

스크립트가 보는 것: Byte(한글 3, ASCII 1, 엔터 1), 2026 최대 Byte 초과, 금칙어(고등학교: 모의고사 ERROR, 고교 블라인드·소논문·청소년단체 WARN), 한자·영어 외 외국 문자, 글머리표·번호·특수문자(`[능력단위: ○○]` 표기는 제외), 명사형 종결, 추상 표현, AI 문체 틀(`student_record_humanize.py` 틀 표의 처방 대상), 윤문 게이트(`--before`: 같은 모듈의 게이트 P0~P6), 학생 간 중복. 사실·과장·항목 적합성과 학교 고유 행사 이름은 사람이 본다. ERROR가 나오면 고친 뒤 출력한다. WARN의 고교 블라인드는 '학교 축제'처럼 일반 명칭이면 무시해도 된다.

코드 실행 도구가 없으면 `1. 지침`의 계산식대로 세고 분량을 "추정"으로 표시한 뒤, 사용자에게 바이트 계산기(위 저장소 `tools/바이트 계산기.html`)로 확인하라고 안내한다.

## 6단계: 출력

`1. 지침`의 출력 형식을 쓴다. 분량 줄에는 스크립트가 센 값을 쓰고 "계산"으로 표시한다. 기계 검사 결과 요약을 한 줄 덧붙인다. 1·2학년 공통과목이면 1·2 합산 분량을, 3학년 세특이면 대입 수시에 1학기분만 제공된다는 점을 확인 목록에 한 줄 넣는다.

## 주의사항

- 이 스킬은 초안만 쓴다. 나이스 입력은 사용자가 한다.
- 기준은 2026학년도 **고등학교** 기재요령과 기재 길라잡이다. 다른 학년도나 중학교면 먼저 알리고 해당 기재요령 확인을 권한다. 2027학년도에는 3학년도 2022 개정 교육과정으로 바뀐다.
- '기재방법'은 지키고 '기재예시'는 참고자료다. 의미가 바뀌지 않는 범위에서 다르게 쓸 수 있다.
- 소속 학교와 시도교육청의 생성형 AI 활용 지침이 있으면 그것이 먼저다.
