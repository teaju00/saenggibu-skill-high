# 고등학교 생기부 스킬 사용 가이드

설치는 README의 '설치'를 보십시오.

## 1. 준비

- **켜 둘 것**: 코드 실행(분량 계산 · 검사용), 추론 수준은 **높음**(고를 수 있으면).
- **성취기준 원문**(세특): `0. 내 교과 정보`에 붙여 두면 매번 묻지 않습니다.
- **관찰 메모**: `4. 교사 입력 양식`을 채우면 질문이 줄어듭니다. 학생이 고른 것, 막힌 곳과 넘은 방법, 판단의 근거가 된 장면이 있으면 좋습니다.
- **학년**: 2026학년도는 1·2학년(2022 개정)과 3학년(2015 개정) 규칙이 다릅니다. 요청할 때 학년을 함께 적어 주십시오.
- **목표 분량**: 숫자만 쓰면 Byte입니다. 안 쓰면 세특·창체 1,500Byte, 행특 900Byte로 씁니다. 1·2학년 공통과목(공통국어, 공통수학, 공통영어, 통합사회, 통합과학, 한국사, 과학탐구실험)은 1·2를 합쳐 1,500Byte입니다.

## 2. 개인정보와 고교 블라인드

- 학생은 '학생1'처럼 **기호**로만 씁니다. 대응표는 교사만 갖습니다.
- 실명, 학번, 생년월일, 가족, 건강, 상담, 학교폭력 내용은 넣지 않습니다. 날짜가 붙은 사건이나 다른 학생 이름도 뺍니다.
- **학교명, 재단명, 학교 축제명, 학교 별칭**은 학생부 어디에도 쓸 수 없습니다. 메모에도 '학교 축제', '교내 프로그램'처럼 일반 명칭으로 적어 주십시오.

## 3. 부르기

- Claude Code(플러그인): `/생기부`
- 그 밖의 앱: "고2 세특 써줘", "3학년 행특 초안 써줘"처럼 말로 부릅니다.

```
/생기부 2학년 확률과 통계 세특, 1,500Byte. 학생1. 조건부확률 문제를 전체 경우로 계산해 틀렸다가
조건에 맞는 경우만 표로 다시 나눠 해결함. 모둠원에게 설명하다 독립 여부를 확인하지 않은 자기 실수를 찾음.
```

## 4. 질문에 답하기

AI가 먼저 몇 가지를 묻습니다. 아는 것만 답하고, 모르면 "**없음**"이라고 하시면 됩니다. AI는 없는 내용을 지어내지 않고 빼거나 `[교사 확인 필요]`로 비워 둡니다.

**글이 짧다고 물을 때**: AI 문체(과장 평가어, 총평 등)를 걷어 내면 글이 짧아집니다. AI는 문장을 늘려 채우지 않고 "그렇게 보신 장면이 있을까요?"라고 묻습니다. 장면이 있으면 알려 주시고, 없으면 "없음"이라고 하시면 짧은 채로 나옵니다.

## 5. 확인하고 입력하기

초안 끝에 '교사 확인 필요' 목록이 붙어 나옵니다. 입력 전에 네 가지만 하십시오.

1. 목록의 **사실 · 과장** 줄을 보고, 메모에 없던 내용이 들어왔는지 확인합니다.
2. 본문의 `[교사 확인 필요: ○○]` 자리를 채우거나 지웁니다.
3. 학교를 알 수 있는 이름(행사·프로그램·축제 이름 포함)이 없는지 봅니다.
4. 분량이 '추정'으로 나왔으면 `바이트 계산기.html`로 다시 셉니다.

이 확인을 마쳤다면 초안을 그대로 입력해도 기재요령(고등학교 유의사항 5-다)에 어긋나지 않습니다.

**3학년 세특**은 대입 수시 전형자료에 1학기 입력분만 들어갑니다. 1학기에 관찰한 내용은 1학기 칸에 입력하십시오.

## 6. 여러 학생

- `4. 교사 입력 양식`의 D 양식을 씁니다. 공통 정보는 한 번만 적습니다.
- **5~10명씩** 묶고, 묶음마다 새 대화를 엽니다. 그래야 품질이 고르고 사용량도 덜 듭니다.
- 고등학교 세특은 모든 학생에게 씁니다. 메모가 적은 학생은 확인된 내용만 짧게 나옵니다.
- 입력 전에 기호와 학생이 맞는지, 학생 사이에 같은 문장이 없는지 확인합니다.

## 7. 자주 묻는 것

- **스킬이 안 켜집니다**: "고2 세특 초안 써줘"처럼 학년과 항목 이름을 넣어 다시 부르십시오. 학교 Google Workspace 계정은 Gemini 스킬이 막혀 있을 수 있습니다.
- **ERROR가 나왔습니다**: 나이스에 넣으면 안 되는 것(분량 초과, 대회 · 수상 · 모의고사 · 상호명 · 대학명, 한자 등)입니다. 그 자리를 고쳐 달라고 하십시오. WARN은 확인할 거리입니다. '학교 축제'처럼 일반 명칭에 붙은 고교 블라인드 WARN은 넘어가도 됩니다.
- **글이 밋밋합니다**: 사실만 남긴 결과입니다. 길게 하려면 학생이 한 일을 더 알려 주십시오.
- **중학교도 되나요**: 이 스킬은 고등학교 기준입니다. 중학교는 [중학교 생기부 스킬](https://github.com/teaju00/saenggibu-skill)을 쓰십시오.
