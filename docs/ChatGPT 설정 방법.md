# ChatGPT에서 쓰기 (고등학교)

ChatGPT에는 스킬 기능이 없어서 지침과 참고 파일을 직접 넣어 씁니다. 처음 한 번만 설정하면 됩니다.

## 설정 (처음 한 번)

1. `0. 내 교과 정보 (교사가 채움).md`를 메모장으로 열어 과목·학년·학기·과목 유형과 이번 학기 **성취기준 원문**을 채우고 저장합니다.
2. ChatGPT에서 **프로젝트**(또는 맞춤형 GPT)를 새로 만듭니다.
3. `1. 지침 (붙여넣기용).md`를 메모장으로 열어 **내용 전체를 복사**해 지침(instructions) 칸에 붙여 넣습니다.
4. 나머지 md 파일 여섯 개(0, 2, 3, 4, 5, 6번)를 **파일**(지식)로 올립니다.

프로젝트를 만들 수 없으면, 대화를 시작할 때 md 파일 일곱 개를 모두 첨부하고 "첨부한 1번 지침대로 해 주세요"라고 쓰면 됩니다.

## 쓰기

- 그 프로젝트 안에서 "2학년 물리학 세특 써 줘"처럼 학년과 항목을 말하고 관찰 메모를 붙입니다.
- 학생은 '학생1'처럼 기호로만 씁니다. 실명·학번은 넣지 않습니다. 학교명·학교 축제명도 넣지 않습니다.
- 분량은 `바이트 계산기.html`을 두 번 눌러 열고 초안을 붙여 넣어 확인합니다. 인터넷 없이 동작하고 글이 밖으로 나가지 않습니다.
